## 👨‍💻 About This Repository

Welcome to my **NetworkWalks Cybersecurity Internship Repository!**

This repository documents my hands-on learning journey through practical cybersecurity tasks. It includes exercises related to **Footprinting, Open-Source Intelligence (OSINT), Reconnaissance, and Network Scanning** using industry-relevant tools.

My goal is to strengthen my technical knowledge, develop practical cybersecurity skills, and gain experience with real-world security assessment techniques in authorized environments.

## 🎯 Tasks & Practical Activities

### 🔎 01. Footprinting with Kali Linux
- Performed basic reconnaissance and footprinting.
- Explored publicly available information.
- Practiced information gathering using Kali Linux tools.

### 🌐 02. theHarvester – OSINT
- Gathered publicly available information.
- Identified email addresses and subdomains.
- Explored digital footprints associated with the target domain.

### 🕸️ 03. Maltego – Visual Reconnaissance
- Explored relationships between digital entities.
- Analyzed domains, IP addresses, and related information.
- Created visual graphs to understand connections.

### 📡 04. Zenmap – Network Scanning
- Identified local IP addresses and network subnets.
- Performed Ping Scans to discover live hosts.
- Examined IP and MAC address information.
- Explored network topology visualization.
